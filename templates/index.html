PRIVACY & SECURITY

Designed with safe defaults.

This Hacktoberfest prototype uses sample emails only. VEYRA does not ask for, store or transmit Gmail or Outlook passwords.

  • API keys stay on the server.
  • No real email credentials are stored.
  • Demo data is clearly separated from future integrations.
  • Real OAuth is planned for a future phase.
